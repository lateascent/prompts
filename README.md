# prompts

Copy-paste AI prompts I actually ran before posting about them on X ([@lateascent](https://x.com/lateascent)).
Plain steps for beginners and freelancers.

## The one rule

Every prompt here starts **read-only**: the AI looks, explains and suggests. Anything you can't undo (deleting, paying, sending, changing settings) stays with you.
Never paste passwords, codes or screenshots of them into any AI chat.
