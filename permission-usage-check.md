# Which apps used your camera, mic or location (advice only)

Open the permission screen, type the app names into an AI chat, get a list of what to restrict. The AI only advises. You change the settings.

## 2 minutes, no tools

- **Samsung:** Settings > Security and privacy > Privacy > Permission usage. Pick Camera, Microphone or Location to see which apps used it in the last 24 hours.
- **iPhone:** Settings > Privacy & Security > App Privacy Report. Turn it on first, it shows the last 7 days.
- Type the app names. Do not upload a screenshot: it can show other apps, your name and your account.

## Prompt

```
Apps that used my camera, mic or location in the last 24 hours: [paste names].
For each one, does it need that access to work? Say which to set to "only while using the app" and give the exact setting for my phone: [Samsung model or iPhone model].
Advice only. I change the settings myself.
```

## Rules

- Do not paste passwords, codes or card numbers into any AI chat.
- A camera app, a map or a call app using the matching permission is normal. Limit an app only if you do not need that feature from it.
